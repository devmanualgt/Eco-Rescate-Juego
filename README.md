## Prerequisitos

Descargar e instalar el gestor de paquetes `npm` usando `nvm` 

*Instalar version > 20.18.0*

[Instrucciones de npm]


Verificar que la instacion fue correcta
```bash
  npm -v
```
Respuesta version igual o mayor a `10.8.2`


Descargar e instalar el gestor de paquetes `pnpm` para el uso de monorepo

[Instrucciones de pnpm]

## Ejecutar Local

Clonar el proyecto
```bash
  git clone https://github.com/devmanualgt/Eco-Rescate-Juego.git
```

Navegar al direcctorio del proyecto

```bash
  cd Eco-Rescate-Juego
```

Instalar dependencias

```bash
  pnpm install
```

### Iniciar Entornos

Cliente (vite + phaser)

```bash
  npm run client
```

Servidor (node + express)

```bash
  npm run server
```

Todo

```bash
  npm run dev
```
